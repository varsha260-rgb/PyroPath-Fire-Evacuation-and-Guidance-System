# PyroPath 🔥

## Overview
PyroPath is an IoT-based Fire Evacuation and Guidance System designed to detect fire and smoke in real time and assist users during emergency situations.

## Features
- Real-time flame detection
- Smoke monitoring
- ESP32-based wireless communication
- Web dashboard monitoring
- Fire evacuation guidance

## Technologies Used
- ESP32
- Arduino IDE
- Node.js
- HTML
- CSS
- JavaScript

## Project Status
Completed and tested successfully.
